# Task 4 - Aggregate Functions and Grouping

## Objective
To use SQL aggregate functions and grouping techniques to summarize and analyze data.

## Database
Library Management System

## Operations Performed
- COUNT() to count records
- SUM() to calculate total values
- AVG() to calculate average values
- MIN() to find the minimum value
- MAX() to find the maximum value
- GROUP BY to group records by category
- HAVING to filter grouped results
- ROUND() to round aggregate values
- COUNT(DISTINCT) to count unique values

## Tools Used
- MySQL
- phpMyAdmin
- XAMPP

## Key Concepts
- Aggregation
- Grouping
- Aggregate Functions
- GROUP BY
- HAVING

## Outcome
Successfully used aggregate functions and grouping to summarize and analyze data from the Library Management System database.
